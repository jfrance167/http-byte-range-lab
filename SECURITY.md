# Security model

This is a bounded offline teaching API/CLI, not an origin server or HTTP security filter.
Only invented normalized metadata is authorized. No real requests/resources/content,
network, multipart or response emission. Counterfactual geometry does not grant access,
authenticate validators, enforce consistency or prove resumable transfer correctness.

Untrusted synthetic JSON can try numeric/type confusion, cyclic/custom API containers,
oversized allocation, malformed fields hidden behind ignore/unsupported gates or report
injection. Exact builtins, byte/token/depth/tree/cardinality/field limits, explicit cycle
rejection, whole-case validation, integer arithmetic and inert escaping mitigate those
interface threats. The stdlib is JSON syntax authority; API compact re-encoding measures
admission bytes only. No universal canonicalization or hard resource-containment claim.

Supported coding spellings describe supplied encoded octets only; no codec is invoked.
Unknown lengths/basis/unit/coding/features conservatively make the case unsupported
even with absent Range or a bypassed baseline. Known geometry survives handling-only
unknown informational/If-Range/empty-suffix context. Null count is not zero; error-body
length is never computed. Range-invalid ignore and unsatisfiable rejection are explicit
lab policies; real origins may make permitted alternatives.

No raw tags/dates/headers/URL/body, external model/tool callbacks or content-derived
filesystem/command choices. Reports retain synthetic declarations, so they are not a
redaction tool. JSON escapes Unicode, Markdown encodes every derived character. Only
parse/evaluate are public untrusted-input APIs; reporter helpers require their records.

CLI-selected host paths/standard descriptors and process are trusted. Exclusive creation
prevents routine overwriting, with input alias rejection and failure cleanup of the
new file. No hostile filesystem-race/special-file/durability/atomic-output guarantee.
Stdout delivery is nontransactional. Failed streams redirect to the OS null sink to
avoid shutdown retries, or detach from Python's slots if redirection fails. Diagnostics
have one checked write/flush, no fallback, and fixed codes without native paths/text.
Empty/NUL paths fail before access, explicit empty output cannot select stdout, and
help delivery is checked. General host process failures remain outside guarantees.
Local test/verifier
subprocesses use only fixed reviewed interpreter commands, no shell or input arguments.

Local checks are Windows CPython 3.13.7 only. Manual boundary review remains pending.
No independent audit, live origin/browser, upstream test execution, other runtime/OS,
hosted CodeQL/CI, dedicated secret/history scan or dependency supply-chain certification.
Do not publish/merge/deploy without separately authorized review. Prior lab limitations
remain; this lab does not repair or validate them. No automatic external reporting.
