# Decisions — October 5, 2026

- Original stdlib model: no response/file/network framework needed for declared geometry.
  Actual Werkzeug/aiohttp examples inform conventions, not an executable dependency.
- Inclusive external endpoints and separate byte count avoid hidden half-open conversion.
  Tiny index enumeration independently tests the formula over 704 invented small cases.
- Keep counterfactual GET geometry apart from actual method applicability and assumed
  handling; independently known math survives ignore/handling-only unsupported results.
- Global scope conservatively takes priority even for absent Range. Frozen contract
  explicitly labels this a lab restriction, not real protocol evaluation behavior.
- Reversed closed range is admitted INVALID_RANGE; suffix0 is valid UNSATISFIABLE;
  positive empty suffix SATISFIABLE_EMPTY never fabricates an interval/header/status.
- If-Range is a declared result, avoiding duplication of precondition/validator work.
  Coding comparison ASCII-insensitive while token spelling and encoded-byte basis remain.
- Corrected five fixture-authoring null inputs transparently, without changing independent
  expected answers or contract. Preserve initial receipt/artifacts separately, current
  corrected receipt explicit; do not claim all corrected input bytes predate code.
- Stdout failure redirects only its failed descriptor to the OS null sink; evidence
  reproduced exit120 before fix and verifies ordinary closed-pipe exit1 afterward.
- No new repository/install/publication; implementing-agent ECC self-review and local
  tests do not replace manual boundary review or actual HTTP/runtime validation.

## Checked CLI delivery after coordinator review

Distinguish absent output (None) from explicitly empty output, and reject empty/NUL paths
before access. Check help and fixed diagnostic writes/flushes as well as report delivery.
Use no diagnostic fallback; preserve intended exits even if stderr fails. Null redirection
or detaching failed Python stream slots prevents shutdown retries in tested cases; this
is not a general guarantee against host process failure.
